# Try-demo scheduler: Mobbin research on date and time pickers

Date: 2026-11-13

Scope: evidence only. No design recommendations are made in this file. A second agent interprets it.

## 1. Method

- Source: Mobbin MCP (`search_screens`, `search_flows`). `search_sections` was loaded but not used. Read-only: no save, collection or comment calls were made.
- Queries were generic. No company or user information was put in any query.
- Mobbin results are images plus metadata (app name, platform, ID, URL). There are no text descriptions, so every field in the evidence tables was read from the preview image. Where a field could not be read from the image it says "not visible in result". Nothing from memory is included (no "UNVERIFIED (from memory)" entries exist in this file).
- Tool platform filter only offers `web` and `ios`. Android and mobile-web (responsive) screens could not be requested.
- Flow results return a subset of each flow's screens as preview images. Those previews cannot be mapped to individual screen IDs, so flows are recorded at flow level with the previews described.
- Mobbin example data (dates in 2023 to 2026, mock names) is shown as captured. Time zone labels in many examples read Indochina, Jakarta, Bangkok or Kuala Lumpur; how those zones were set (detected or chosen) is not stated in any result.
- Tool calls: 15 Mobbin calls (13 `search_screens`, 2 `search_flows`) plus 1 tool-schema load.
- Kept: **99 screens** (53 web, 46 iOS) and **8 flows** (web and iOS), from **78 distinct products**.

Family codes used in the tables: A month calendar + time list for the chosen day; B horizontal date strip or week row + times; C multi-day columns or week grid of times; D typed or select inputs; E wheel or spinner; F next-available, earliest-slot or quick-pick shortcut; G time zone display or control; H unavailable, full or empty state; I container (modal, sheet, inline card, summary); J time-of-day grouping; K date list instead of calendar.
