# Page agent notes

Each page agent writes its own `notes/<slug>.md` (never a shared file, so parallel agents cannot conflict).
If a page has nothing to report the file contains `No notes.`

## Entry format

### <short title>
- Type: shared-change-request | unmatched-section | unmatched-image | deviation
- Where: file or section index
- Detail: what is wrong or needed, with the reference screenshot path
