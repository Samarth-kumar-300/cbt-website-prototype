# /research

Only two studies are listed, as on the live site. The third entry from the first build (the Indian patent) was removed from the cards and from `studies.ts`; the patent is on `/achievements`.

New page built from the "Research" section of `/resources` (reference/resources/copy.json, id `research`).

- Header: shared `PageHero` (title "Research", subtitle from the original section intro). The section's own h2 was dropped.
- Cards: one tinted ruled-notepad sheet each (`ResearchCard.tsx`), in a 1-column / 2-column (sm) grid (`ResearchGrid.tsx`, a client component). The whole sheet is the `<Link>`. Data in `content.ts` is `href`, a short `title` (40 characters max) and a one-sentence `description` (80 characters max, two lines max). The formal paper titles live only on the detail pages (`studies.ts`). Every figure in a description comes from that study's own page.
  - Each paper is a lighter tint of that card's old badge colour (`tone` in `content.ts`, shades in `TONES` in the component): teal `#eef9fa` for the 12-month study and amber `#fffbef` for the 90-day study. Rules, margin line and a 1px edge are deeper shades of the same hue. The title is brand teal (`text-brand-teal`, 6.9:1 or better on the papers) and the description `#4a5658` (7.1:1 or better). Constants sit at the top of the component.
  - Read-time badge under the description (`minutes` in `content.ts`, "1 min read" for both: each study is about 120 words): a pill on its own ruled row, filled with the card's folder colour (`pocket`) with a deeper ink (`badgeInk`, 7:1 or better).
  - Title in the brand heading font (Nunito) at weight 600, 20px mobile / 24px lg, with `text-balance`. Description 15px / 16px, `line-clamp-2`. The sheet stays straight (no tilt); min-height 360px, 460px from lg.
  - Logo: `public/research/logo-symbol.webp` (from `illustrations/logo_symbol.webp`), 28 × 25px, decorative (`alt=""`), top-right at 16px from the top and 20px from the right. The description sits one blank ruled row below the title. The first three ruled rows are left empty for the clip and the logo.
  - Ruling: a 1px rule at the bottom of each `--rule` row (28px mobile, 32px lg), drawn as a tiled linear-gradient on the whole sheet, so it runs to the bottom edge. `--rule` is also the line-height of both text blocks; `--rule-shift` (-1px, 1px lg) is tuned so descenders clear the rules. Checked on the built page at 375 and 1440.
  - Entrance (`ResearchGrid.tsx`, GSAP): each paper starts in a folder pocket with only the top of the sheet showing, is pulled up out of it, the folder drops away, then the clip draws on (DrawSVG) and snaps down (CustomBounce). It plays once when the grid scrolls into view (ScrollTrigger) and takes 1.75s in total, both papers included (the timeline is built in its own seconds, then sped up with `master.duration(1.75)`; the second paper starts a little after the first). Offsets use `yPercent`, so it holds if the layout resizes. The server HTML shows the finished papers with the folders hidden (`invisible`), so it reads with no JavaScript or with reduced motion (the animation only runs under `prefers-reduced-motion: no-preference`). With scripting on, `.paper-grid` stays at opacity 0 until the grid sets `data-paper-ready` before first paint, with a 3s failsafe in `globals.css`, so the finished papers never flash first. The cards use no `transform` of their own: the hover lift uses the CSS `translate` property so it never fights GSAP. The grid does not use `RevealStagger` (its idle, pending, shown states change within one frame at load, so it never animates a group that is already in view).
  - 3px corners, soft neutral shadow (the `.card-lift` teal hover shadow is overridden), focus-visible ring. The link's accessible name is the title plus the description.
- Cards link to `/research/<slug>` (detail pages, copy in `studies.ts`). The live site's `/resources/research/<slug>` URLs redirect there (`next.config.ts`).
- CTA: "Want results like these?" / "Book a demo" -> `/try-demo` (same as Testimonials).
